# Vérification de la consigne Foyer

Source originale : https://lux-guide.github.io/recrutement-ia/#repondre

**Sujet AI engineering n°1 : un sinistre et les conditions générales.**

| Attente | Réalisation | Limite |
|---|---|---|
| Petit produit fonctionnel et déployé | Demo HTML autonome accessible en URL | Quatre exemples, un seul contrat |
| Couvert ou non, pourquoi, quelles clauses | Statuts provisoires, questions ouvertes et PDF page par page | Aucune décision sans conditions particulières |
| Reconnaître les inconnues | Tri-state et abstention hors périmètre | Classification lexicale fragile aux négations |
| Au-delà du PDF collé dans un chatbot | Index de clauses manuel et prototype PDF versionné/BM25 | Pipeline pas encore raccordé à la démo |
| Centaines de contrats | Test d'isolation sur 200 contrats synthétiques | Pas de benchmark de 200 PDF réels |
| Code modulaire | Sources JS, build autonome, Python CLI | Moteur d'analyse statique, pas de RAG |
| Propriété des données | Contrat Baloise public, exemples fictifs | Aucun contrat d'assuré fourni |

**À ne jamais prétendre :** que l'IA générative est utilisée ici, que les clauses paraphrasées couvrent tout le contrat, que 200 données synthétiques démontrent une performance industrielle, ou qu'une garantie est souscrite sans conditions particulières.
